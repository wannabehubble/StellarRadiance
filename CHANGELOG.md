# Changelog

All notable changes to StellarRadiance.

- **2.9.1:** Author credit in the info box, which now uses a cleaner layout.
- **2.9:** Input options renamed to Stars-only / Starless / Combined. The preview grows when you enlarge the dialog window.
- **2.8:** New **Image** menu to pick any open image. Advanced settings always start hidden.
- **2.7:** New **Whole image (1/3 res)** preview, the new default view.
- **2.6:** The Refresh button is now called Preview, and the help box tells you to press it to start.
- **2.5:**
  - Modes renamed to Stellar and Non-Stellar.
  - The blend mode option was removed; the glow is always screened on.
  - Wider preset menu.
- **2.4:** Renamed from StarGlow to StellarRadiance.
- **2.3:**
  - New Natural presets for Non-Stellar mode.
  - Star removal now runs only when you press Preview or OK.
- **2.2:** New Stellar presets, tuned by the author.
- **2.1:** Highlight protection and mask feather.
- **2.0:** Non-Stellar (starless) mode, with its own settings.
- **1.x:**
  - Live preview.
  - Presets and saved settings.
  - StarNet2/StarXTerminator integration.
  - PixInsight preview-box support.
  - Glow saturation and SCNR.
